Counting by Weight Before Counting by Formula

Counting often begins with a list. How many ways are there to choose a subset, make change, walk on a grid, or build a string? Generating functions ask for a different object first. Instead of only counting the final number, assign each object a weight and place it into a power series.

If there are a_n objects of size n, the ordinary generating function is $A(x)=a_0+a_1x+a_2x^2+\cdots$. The coefficient of $x^n$ is the count we want. This looks like a detour until algebra starts doing the bookkeeping.

The key rule is that addition means choice among disjoint families. If a structure is either type A or type B, its generating function is A(x) + B(x). Multiplication means building a pair whose sizes add. If an object is made by choosing one A object and one B object, then the coefficient of x^n in A(x)B(x) sums over all splits i + j = n.

This multiplication rule is the source of convolution. It turns a counting argument into a product of series. You no longer need to list every split by hand after the model is right.

A first example is subsets. Each item is either absent, contributing 1, or present, contributing x. For n independent items, the generating function is (1 + x)^n. The coefficient of x^k is the number of k-element subsets, namely the binomial coefficient. The binomial theorem is now a counting machine: expand the product of n tiny decisions.

Weights can be richer than size. If items have costs, values, colors, or dimensions, the exponent can track one attribute or several variables can track many attributes. A two-variable series might record size with x and number of red pieces with y. Coefficients become a table indexed by several statistics.

This is why generating functions are teacher-friendly. They force the model to explain what an object is made from. Is it a disjoint choice? Add. Is it a sequence of independent parts? Multiply. Can parts repeat? Use a geometric series. Is order irrelevant? Choose factors that enforce that.

The first lesson is to count by weight before chasing a formula. Once the weight system matches the combinatorial construction, algebra becomes an assistant. It stores cases, combines choices, and leaves the desired count in a coefficient waiting to be read.
